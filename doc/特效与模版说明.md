# 特效与模版说明：可配置特效、Cue 模版、舞台与灯具表

本文说明节目编辑器在特效、Cue 模版、预览舞台和灯具表上的增强，以及工程文件里对应的新字段。
设计参考了 grandMA3 的 [Phaser](https://help.malighting.com/grandMA3/2.2/HTML/phaser.html)（步的宽度、过渡、加减速）与 [MAtricks](https://help.malighting.com/grandMA3/2.0/HTML/matricks.html)（Block / Group / Wings / Shuffle）、ETC Eos 的特效编辑器，以及 QLC+ RGB 脚本“由效果自己声明可调参数”的做法（内容已改写）。界面沿用中文说法，“?”说明卡里注明对应术语。

## 1. 引擎能力（数值曲线、颜色序列、多灯分布）

所有新字段都是可选的：旧工程不带这些字段，播放结果与以前逐位相同（有黄金向量守护）。

### 1.1 数值曲线 `ValueCurve`

| 字段 | 作用 | 说明 |
|---|---|---|
| `period` | 按时间计的周期：`{kind:"ms", ms}` 或 `{kind:"beats", beats}` | 给出时忽略 `cycles`；周期可以比片段长；按拍时跟随工程 BPM（没设节拍按 120 BPM）。拉长片段不会改变速度 |
| `sync` | `"clip"`（默认）或 `"beat"` | `beat`：相位从工程第一拍（`tempo.offsetMs`）算起，片段起点不在拍上也合拍 |
| `transition` | 0~1，省略为 1 | 波形在一个周期的这部分时间里走完，余下时间保持（取自 MA3 的 Transition）。三角波 50% = “快速起落、休息半拍” |
| `ease` | 关键帧同款缓动 | 作用于过渡内的进度；斜坡也会被缓动 |
| `steps` | 新形状 `steps` 的每一步（0~1） | 一个周期均分成若干步；没有缓动时保持，有缓动时在过渡占比内滑向下一步 |
| `seed` | 随机 / 噪声的种子 | 给出时每台灯的随机序列不同；省略时所有灯同一序列（旧行为） |

新形状：`noise`（平滑噪声，相邻随机值之间按 S 曲线插值，适合烛光、火焰）、`steps`（自定义步进）。

界面：Cue 属性 → 强度 → 曲线，新增“周期（次数 / 毫秒 / 拍）”“按节拍对齐”“过渡 %”“缓动”，方波有“占空比”，随机 / 噪声有“每台灯不同”和“换一组”，步进有“每一步（%）”输入（逗号分隔，例如 `100, 0, 0, 0`）。在三种周期方式之间切换时保持当前速度。频闪安全提示按真实周期和步进的亮暗次数计算。

### 1.2 颜色序列 `{kind:"cycle", cycle}`

```json
{ "kind": "cycle", "cycle": { "colors": [{ "kind": "rgb", "rgb": [255,0,0] }, { "kind": "kelvin", "kelvin": 3200 }],
  "blend": "smooth", "cycles": 1, "phase": 0, "period": { "kind": "beats", "beats": 2 } } }
```

- 每个周期依次走过这组颜色（首尾相接）；`blend` 为 `smooth`（插值）、`step`（跳变）或 `hue`（沿色轮最短方向，彩虹不经过灰色）。
- 计时字段与数值曲线相同（`cycles` / `period` / `sync` / `phase` / `transition` / `ease`），`transition` 按每种颜色计。
- 与关键帧不同，颜色序列**受相位分布影响**：可以做颜色追逐、彩虹波浪。时间线上画成按周期重复的色带。
- 在 Cue 属性里改颜色或打关键帧时，序列换成固定值或关键帧（可撤销）。

### 1.3 多灯分布 `Spread`

| 字段 | 作用（对应 MAtricks） |
|---|---|
| `values["phase.intensity"]`、`["phase.color"]`、`["phase.<属性>"]` | 只错开某一层的相位；原来的 `phase` 仍作用于全部层，单层的键优先 |
| `blocks` | Block：连续 n 台取同样的值 |
| `groups` | Group：每 n 个位置重复一遍分布 |
| `shuffle` | Shuffle：按种子确定性地打乱成员顺序 |
| `colors` | 静态颜色分布：沿成员铺开一组颜色（`blend` 同上；覆盖外观的颜色层，色相分布仍叠加在上面） |

成员位置的计算顺序：先按 `order`（成员 / 反向 / 舞台 X / 舞台 Y）排序，再打乱，再成块、分组，最后分翼。

### 1.4 兼容性与校验

- Rust 端新字段全部 `serde(default)`；`NumParam::Curve` 与颜色序列装箱，避免撑大每个参数。
- 前端 zod 校验：周期 20~600000 ms 或 1/16~128 拍；步进最多 64 步、每步 0~1；种子为 32 位无符号整数；未知的 `phase.*` 键被拒绝。
- 黄金向量新增 5 个外观片段用例（静态颜色分布、颜色序列按颜色层相位分布、成块、步进按拍、单层相位），Rust 与 WASM 同时校验。
- WASM 新增 `se_sample_num_at`（带节拍、节目时间、成员序号的取值），属性面板显示播放头处的值用它。

## 2. 可配置特效（插入后仍可改参数）

### 2.1 片段记住特效

从特效库插入（点击“插入”、双击卡片或拖到轨道）时，片段里保存一份特效快照 `LookClip.fx = { def, params }`：

- `def` 是特效定义的副本（去掉 `builtin` 标记）：之后改了或删了“我的特效”、换一台电脑打开，片段都不受影响；
- `params` 是插入时的参数。

在 Cue 属性页顶部的“特效参数”分区里改参数，片段的外观与分布按当前轨道的成员数重新生成（一步撤销）；“恢复默认”回到特效的默认参数。
多选同一个特效生成的片段时一起改。

以下操作会让片段**转为普通外观**（删除快照，保留当前效果，可撤销）：手动修改强度 / 颜色 / 属性层、修改多灯分布、从编程器更新到片段、点“转为普通外观”。转换时会有读屏提示。

引擎不读 `fx`：后端 `LookClip` 不认识这个字段，解析时直接忽略（与轨道的 `heightPx` 相同）。

### 2.2 特效定义 v2：可调参数

特效文件升到版本 2（版本 1 照常读取）。特效可以在 `params` 里声明自己的可调参数，在层里用 `"$参数名"` 引用：

| 类型 | 值 | 控件 |
|---|---|---|
| `number` | `min`~`max` 的数 | 数字输入（可带单位） |
| `percent` | 0~1 | 百分比输入 |
| `color` | `[r, g, b]` | 取色器 |
| `colors` | 颜色列表（`min`~`max` 个） | 一排取色器，可增删 |
| `choice` | `options` 里的一个值 | 下拉 |
| `boolean` | 真 / 假 | 复选框 |

- 数值字段（`lo` / `hi` / `center` / `amp` / `cycles` / `phase` / `duty` / `transition`）可引用数值或百分比参数；`shape` 可引用选项全是形状名的选择参数；颜色层的 `rgb` / `colors` / `blend` 可分别引用颜色、色表、选项全是过渡方式的选择参数。
- 校验时检查引用：引用不存在或类型不对的条目被跳过，并在特效库里列出原因。参数 `id` 不能重复，数值参数的默认值必须在范围内。
- 层的新写法：`transition`、`ease`、`steps`、`seed: true`（随机每台灯不同），以及 `duty` 用在随机波形上时表示点亮密度。

### 2.3 生成规则

- 周期按时间计：每层写 `period`（毫秒或拍），层的 `cycles` 是速度倍数（2 = 两倍速）；`once` 的层整段只走一次。拉长片段不再改变速度。
- 颜色层生成颜色序列（不再展开成关键帧），`spreadBy: "phase"` 时颜色也按成员错开。
- 通用参数之外新增：`blocks`（成块）、`groups`（分组）、`shuffle`（打乱的种子）、`sync`（按节拍对齐）、`seed`（“换一组”随机的变化量，与每层的种子混合）。
- 每台灯不同的随机层，种子由“特效 id + 层名”稳定算出：同一特效每次插入相同，“换一组”后才变化。
- 时间级联（`spreadBy: "delay"`）的毫秒数按插入时的节拍换算；之后改了 BPM，在“特效参数”里随便改一项即可按新节拍重新生成。

### 2.4 插入面板与记住参数

- 素材库里点一下特效卡片打开参数面板。面板按特效声明的参数生成控件，“高级”里是成块、分组、打乱顺序（可“换一种顺序”）、按节拍对齐、换一组随机。
- 每个特效上次用的参数记在编辑器偏好里（`effectParams`，最多 200 个特效），重启软件后还在；“恢复默认”清除记住的参数。读回时结构不合法的条目丢弃，使用时再按特效规整（未声明或越界的可调参数丢弃）。
- 色块按参数的当前值或默认值画出（例如双色交替显示两种颜色）。
- 特效库标题旁有“?”说明卡（`editor.help.effects`）。

### 2.5 经典 RGB 特效的去向

素材库里不再单列 8 种经典特效，它们在特效库里都有可配置的对应条目：

| 经典特效 | 可配置特效 | 说明 |
|---|---|---|
| 呼吸 | 呼吸（`breathe`） | 新增“最暗”参数 |
| 彩虹 | 彩虹（`rainbow`） | 色相分布 |
| 追逐 | 强度追逐（`intensityChase`） | |
| 擦除 | 颜色擦除（`wipe`，新增） | 颜色序列跳变 + 相位分布：颜色依次扫过分组 |
| 渐变 | 流动渐变（`gradient`，新增） | 色表 + 过渡方式（平滑 / 沿色相） |
| 脉冲 | 脉冲（`pulse`） | |
| 闪烁 | 星光闪烁（`sparkle`，新增） | 随机 + 密度 + 线性衰减，每台灯不同 |
| 频闪 | 频闪（`strobe`） | 新增“亮的比例”参数 |

另外新增烛光（`candle`，平滑噪声），随机闪烁（`flicker`）改为每台灯不同的随机序列，双色交替 / 颜色追逐 / 冷暖扫色的颜色改为可调色表。内置特效从 24 个增加到 28 个。

旧工程里的经典特效片段照常播放、照常可以编辑；Cue 属性里的“转换为可配置特效”对 8 种都有效：周期、相位扩散、方向原样带过去，亮度范围映射到强度层的起止值，颜色写进特效的颜色参数（强度类特效会加上一个“颜色”参数）。相位推进方向与经典特效的公式不完全相同，是近似转换。

### 2.6 引擎补充

随机波形 `random` 带 `duty` 时表示**点亮密度**：随机值低于它的周期点亮，其余熄灭；再带 `ease` 时在过渡内从亮衰减到暗。没有 `duty` 的随机波形不变。

## 3. 特效编辑器

在软件里新建、修改“我的特效”，不必手改 `effects.json`。

### 3.1 入口

| 入口 | 行为 |
|---|---|
| 特效库工具条的 “+”（新建特效…） | 从一个空白特效开始（强度正弦，2 拍） |
| 特效卡片右键 → 编辑… | 修改这个“我的特效”（保存时按标识原位替换） |
| 内置特效右键 → 复制并编辑… | 编辑一份副本，保存后成为“我的特效”（内置特效本身只读） |
| Cue 属性 → 存为特效… | 由选中的外观片段反推：特效片段取它的快照（当前参数成为新的默认值）；普通外观片段按层换算 |

“存为特效”的换算规则：曲线成为波形层（第一条按时间计的曲线定出特效周期，其余层的速度换成倍数），颜色序列 / 关键帧成为色表（全是“保持”的关键帧为跳变，否则平滑），固定值成为固定层；分布的相位 / 色相 / 级联换成分布方式与扩散。关键帧只取第一帧的值（特效不表达任意关键帧），没有任何层时给一个固定强度层。

### 3.2 编辑内容

- **基本信息**：名称（写入当前界面语言）、标识（新建时可改，不能与已有的“我的特效”重复）、分组、图标、说明、大小的含义（亮度 / 幅度）。
- **默认参数**：速度（拍 / 毫秒）、大小、相位扩散、多灯分布方式。
- **外观层**：强度、颜色各一层，属性层可添加任意多个。
  - 数值层：固定值或波形；波形有形状、起点 / 终点（或中心 ± 幅度）、速度倍数、相位、占空比 / 密度、过渡、缓动、步进值、每台灯不同、整段只走一次。
  - 颜色层：固定颜色或颜色序列（过渡：平滑 / 跳变 / 沿色相，可设过渡占比）；颜色、色表、过渡方式都可以绑定到参数。
  - 数值字段直接写数字，或写 `$标识` 引用可调参数；形状可选“参数 $标识”。
- **可调参数**：添加百分比、数值、颜色、色表、选项、开关；可设显示名、范围、默认值、选项。

### 3.3 预览与校验

- 对话框顶部是 8 台虚拟灯（编成一组，按舞台从左到右）的实时预览：引擎求值，与实际输出一致；有 Pan / Tilt 层时在色块下画出光点位置。系统开启“减少动态效果”时默认暂停，可手动播放。
- 每次修改都按特效文件的规则校验（引用、范围、空外观等）；有问题时显示原因、隐藏预览，并禁止保存。
- 保存写入用户特效文件（版本 2），读屏提示“已保存特效 …”。
