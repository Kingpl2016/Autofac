# 编辑器增强说明：编程器、色块、时间线

本文说明节目编辑器在编程器、预览色块和时间线三处新增的功能、操作方式与快捷键。
界面沿用剪映式的中文说法；“?”说明卡里注明了对应的 grandMA3 术语，方便熟悉调光台的用户对照。
术语与行为参考了 grandMA3 用户手册的 [Align](https://help.malighting.com/grandMA3/2.5/HTML/operate_align.html)、[Highlight](https://help.malighting.com/grandMA3/2.1/HTML/keyword_highlight.html) 与 [MAtricks](https://help.malighting.com/grandMA3/2.1/HTML/matricks.html) 章节（内容已改写）。

## 1. 编程器

编程器是一块临时工作区：这里的值叠在节目之上（优先级最高），不属于工程、不保存，也不进工程的撤销历史。

### 1.1 “?”说明

每个分区标题旁有一个“?”：鼠标悬停显示一句话，点击弹出说明卡，内容是作用、操作步骤、快捷键和对应的调光台术语。
“?”按钮在分区标题按钮之外，点它不会展开或收起分区。说明文案在语言包的 `editor.help.programmer.*` 下。

### 1.2 顶部全局操作

| 操作 | 说明 | 快捷键 |
|---|---|---|
| 实时输出 | 打开后灯立刻按编程器的值亮；关着时只在预览里看到 | 命令面板 |
| 高亮 | 选中的灯临时满亮白光，不写进编程器；见 1.6 | `H` |
| 撤销 / 重做 | 编程器自己的历史（最多 100 步），与工程撤销互不影响；“清空”也可以撤销 | `Alt+Z` / `Alt+Shift+Z` |
| 移出所选灯具 | 只清掉选中灯的值 | `Alt+K` |
| 清空编程器 | 清掉全部值，同时关闭实时输出与高亮 | `Alt+Backspace` |

### 1.3 强度

- 推子设选中灯的强度；多台灯不一致时显示“混合值”。
- 快捷按钮：满亮、关闭、+10%、−10%。加减在每台灯当前值的基础上进行，保留原有的差异，结果限制在 0~100%。
- 只选一台灯（或它的像素）时出现“Locate 找灯”，再点一次结束。
- 强度按 HTP（取最大）与节目合成。

### 1.4 属性

- 按位置、光束、聚焦、控制分组，只列出选中灯支持的属性（Pan / Tilt、图案、色轮、变焦……）。
- 推子按 0~100% 写入；有能力区间的通道可以直接在下拉里选槽位。
- 只写给支持该属性的灯，部分支持时标出“n/m 台支持”；× 去掉这个属性层。

### 1.5 分布（Align / Fan）

把强度、色相或某个属性按**选择顺序**从起点值 A 分布到终点值 B：每台灯取 `A + (B − A) × 权重`。

| 方式 | 权重（`t` 为在选择里的位置 0~1） | 效果 |
|---|---|---|
| `/` | `2t − 1` | 以中间为轴对称展开：中间一台为 A，最后一台为 B，第一台与 B 关于 A 对称 |
| `<` | `1 − t` | 从第一台起：第一台为 B，逐台回到 A |
| `>` | `t` | 从最后一台起：第一台为 A，最后一台为 B |
| `><` | `1 − |2t − 1|` | 中间最大：两端为 A，中间为 B |
| `<>` | `|2t − 1|` | 两端最大：中间为 A，两端为 B |

过渡决定间距：等距、正弦（两端密中间疏）、先慢（先小后大）、先快（先大后小）。结果按层夹紧（强度 0~100%、属性 0~100%、色相 0~360°）。
色相分布保留每台灯当前颜色的饱和度与明度；属性分布跳过不支持的灯，但它们仍占一个分布位置。面板下方的柱状图实时预览每台灯的取值。

### 1.6 高亮（Highlight）

- 选中的灯满亮白光；通道标注了高亮值（OFL 的 `highlightValue`）的属性写高亮值。
- 高亮跟随选择：用 `Alt+←` / `Alt+→` 换灯时，高亮也跟着换，适合逐台找灯、对焦。
- **预览里始终生效；只有“实时输出”打开时才输出到灯**。实时输出关着时面板会提示。
- 高亮叠在编程器之后（置顶层的最后一条），颜色和属性胜过编程器，强度仍是 HTP。

### 1.7 记录

| 操作 | 说明 | 快捷键 |
|---|---|---|
| 记录为场景片段 | 多台灯不同的值放进同一个片段；没有可用的场景轨道时自动新建 | `Alt+R` |
| 记录到各自轨道 | 每台灯在自己的轨道上建一个外观片段，位置被占用或轨道锁定的跳过 | `Alt+Shift+R` |
| 合并到所选片段 | 把编程器里有的层合并进时间线上选中的外观 / 场景片段 | — |
| 覆盖 | 选中片段的外观换成编程器里的（场景片段的条目换成编程器里的全部灯） | — |

- 长度可以按毫秒或按拍（工程设了节拍时）；可以带淡入（不超过片段长度）。设置会记住，快捷键记录也用它。
- 外观片段取轨道上第一台在编程器里有值的灯的外观；锁定轨道上的片段不更新。每次记录 / 更新是一步撤销。
