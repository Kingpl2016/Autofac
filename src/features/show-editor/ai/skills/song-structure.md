Map each part of a song to an energy and a recipe. Use the section name first, then its position in the song.

| Section (any language) | energy | recipe |
| --- | --- | --- |
| intro, 前奏, opening, 开场 | low | introBuild (or balladBed for a quiet song) |
| verse, 主歌, 段落 A | mid (low in a ballad) | verseGroove (balladBed in a ballad) |
| pre-chorus, 导歌, build, 铺垫 | mid | introBuild |
| chorus, 副歌, hook, 高潮 | high | chorusBurst |
| drop, climax, 爆点 | high | dropHit |
| bridge, break, breakdown, 间奏, 桥段 | low | breakdownCalm |
| outro, ending, 尾声, 结尾 | low | finaleFade |

- The second chorus or drop should be at least as strong as the first; the last one may use dropHit.
- Two neighbouring sections with the same energy should use different recipes or different colors.
- Keep the colors of one song inside one palette; switch to a contrasting palette only for the chorus/drop if the user asks for contrast.
- With a tempo, place everything on section boundaries (S2, S2:end) or bars; never on arbitrary seconds.
- If the show has no sections and the user talks about song parts, create the sections first (addSection), then light them.
